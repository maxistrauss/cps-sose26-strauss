## Task B6: IoTempower (Device Management) Introduction

### 1. Exploring IoTempower Services and Commands

#### Core commands

Those are the core commands to operate within the IoTempower environment like: 

```sh
iot         # starts IoTempower Shell
iot help    # shows help options
iot menu    # open menu for text-based interface
...
```

#### Project commands

```sh
create_system_template [name]   # Creates a new system (Project) with default config files and folder structure -> Used at the start of the project to initialize it
create_node_template [name]     # Creates a new node (microcontroller) with default config files and folder structure -> Used when we need to add a new Microcontroller to our project
...
```

#### Node commands

```sh
compile                                         # Compiles the firmware of the current node
deploy [node-address|compile|adopt|serial]      # Deploys the firmware to the node / first time of serial, then it should be able to do this over Wifi
...
```

#### Gateway Services

```sh
iot service <start|stop|restart|status|view>    # Starts certain services like MQTT, Node-RED, etc. -> Necessary for project development
```

#### MQTT Tools

```sh
mqtt_start                          # Starts Mosquitto to use MQTT
mqtt_listen [topic_or_subtopic]     # Listens to MQTT topics and displays the information -> Used for development to display mqtt data
```

#### RFID reader

```cpp
mfrc522(reader);     // Create a new mfrc522 rfid/nfc tag reader device and sends the the data to topic node_topic/reader and uid in node_topic/reader/uid (works on most NFC tags) as well as picc in node_topic/reader/uid.
```

#### PWM

```cpp
pwm(name, pin/*, frequency is by default 1000*/); /* replace the full comment with , 511 if you want to change the default. */
```

Example: 

```cpp
pwm(blue, ONBOARDLED, 2000);
```

Now you can set the brightness of the onboard-led to 50% sending 512 to [nodename]/blue/set

#### Servo motor

```cpp
servo(name, pin, min_us=600, max_us=2400, turn_time_ms=700);
```

Example: 

```cpp
servo(m1, D4);
```

Now the motor can be controlled via sending to the mqtt-broker to the topic "node_topic/m1/set" the angle to turn the motor to.

#### Ultrasonic distance sensor (RCWL-1601)

```cpp
hcsr04(name, trigger_pin, echo_pin/*, timeout_us is by default 30000*/); /* replace the full comment with , 60000 if you want to change to 60ms. */
```

#### Single RGB led

```cpp
output(name, pin/*, high_command is by default "on"*/ /*, low_command is by default "off"*/); /* replace one full comment with , "myvalue" if you want to change the defaults. */
```

Example: 

```cpp
led(yellow, D7, "turn on", "turn off");

```
