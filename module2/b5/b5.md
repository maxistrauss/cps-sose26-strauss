## Task B5 

```cpp
#include <Arduino.h>

#define LED_PIN 2

void setup() {
  Serial.begin(115200);
  pinMode(LED_PIN, OUTPUT);
}

void loop() {
  digitalWrite(LED_PIN, HIGH);
  Serial.println("LED is on");
  delay(1000);

  digitalWrite(LED_PIN, LOW);
  Serial.println("LED is off");
  delay(1000);
}
```

This code makes an LED blink every second and prints to the Serial Monitor weather the LED is on or off.

In `setup()`, the serial connection is started at `115200` and the LED pin is set as an output. After that, `loop()` keeps switching the LED between `HIGH` and `LOW`, with a 1-second delay in between.

The code is a simple test to check if the board, the pin, and the serial output are working correctly.

### Advantages of PlatformIO

One major advantage of PlatformIO is the better project structure and configuration. The `platformio.ini` file clearly separates board settings, framework selection, build options, and upload options, which makes projects easier to manage, especially when they get larger or when several boards are used in one project.

A second advantage is, that it is an extension for Visual Studio Code, the IDE which most people use already. This gives access to features in VS code and a better editing environment than the classic Arduino IDE. This is especially useful for projects with multiple Files or more complex code.

### Disadvantage of PlatformIO

One disadvantage is that PlatformIO is more complex for beginners. Some things that happen automatically in the Arduino IDE, require more manual configuration in PlatformIO, for example choosing the correct environment, understanding the folder structure, or fixing upload port settings.
