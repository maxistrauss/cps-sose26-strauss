## Task A5

For this task, I chose the Wemos D1 Mini (ESP8266). According to the official Wemos documentation, the board has 11 digital I/O pins and 1 analog input pin. The pin mapping on the board is D0 = GPIO16, D1 = GPIO5, D2 = GPIO4, D3 = GPIO0, D4 = GPIO2, D5 = GPIO14, D6 = GPIO12, D7 = GPIO13, and D8 = GPIO15.

### a)

The board provides 11 digital I/O pins in total. However, not all GPIOs on the ESP8266 are equally safe for normal use, because some are involved in boot configuration and some chip pins are internally reserved for Flash Memory. Pins such as GPIO6 to GPIO11 are not usable as normal GPIOs because they are connected to the onboard flash. That means the board got 11 usable digital pins, but only some of them are fully safe for general-purpose I/O in every situation.

### b) 

The ESP8266 uses GPIO0, GPIO2, and GPIO15 as strapping pins. These pins are checked during boot to decide how the chip should start. For normal boot, GPIO0 must be high, GPIO2 must be high, and GPIO15 must be low. If these levels are wrong during reset or power-up, the board can fail to boot normally or enter flashing mode instead.

The most dangerous pin to accidentally pull to the wrong level is GPIO0. If GPIO0 is pulled low while the board starts, the ESP8266 enters programming mode instead of running the uploaded sketch. This can make it seem like the board is broken, even though it is just booting into the wrong mode.

### c) 

On the Wemos D1 Mini, a pin like D3 actually maps to GPIO0, D4 maps to GPIO2, and D8 maps to GPIO15. If the button in Task B2 was connected to one of these pins, especially D3/GPIO0, that would explain strange behavior during upload or boot. For example, if the button holds GPIO0 LOW when the board resets, the ESP8266 will go into flash mode instead of starting the program normally.

So yes, if I used a strapping pin for the button, that would explain unexpected boot behavior. Safer choices for a normal button input would be pins like D1 (GPIO5) or D2 (GPIO4), because they are not boot-critical in the same way.
